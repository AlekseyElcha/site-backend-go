Обновлённый бэкенд сервиса приёма обращений для domofon-servis-odi.ru
Работает на ask.domofon-servis-odi.ru

Проект был полностью переписан с Python FastAPI на Go net/http
### Tech Stack
* **Backend:**
  * **Language:** Go
  * **Web Framework:** net/http

* **Databases:**
  * **PostgreSQL:** Primary database
  * **Redis:** Caching and sessions

* **DevOps & Infrastructure:**
  * **Containerization:** Docker & Docker Compose
  * **Web Server:** Nginx
